# AI Usage

**Claude Code** (Claude Sonnet 5) built essentially the whole thing, working from an implementation plan I reviewed and redirected several times: Nx scaffolding, server code (Express routes/controllers/services, the SQLite repository), client code (React/Mantine screens, TanStack Query + Zustand, the RTL/LTR Screen 3 layout), the unit/integration/e2e test suites, and this documentation. It also diagnosed two environment-specific issues mid-build (a `better-sqlite3` native-binary/glibc incompatibility, and Playwright's Chromium refusing to install on this old Ubuntu host) and ran the test suites plus manual curl checks to verify the work. For a later visual redesign pass, I brought in a UI/UX spec drafted by **ChatGPT** (a "modern SaaS dashboard" treatment) as input, directed several explicit deviations from it (kept the original "Fetch"/"History" button text, dropped a redundant Back button, reversed a documented filtering decision, cut a sorting feature that no longer fit), and had Claude Code implement the result. All decisions and tradeoffs are in `DECISIONS.md`.
